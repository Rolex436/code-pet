# Changelog

## 0.1.0 - 2026-11-06

- First release.
- Animated pet in its own Activity Bar sidebar.
- Four moods: happy, excited, idle and sleepy.
- Edits and saves raise an activity score that slowly fades.
- Git commits make the pet excited for a few seconds.
- Activity is saved between VS Code sessions.
- Commands: Show Pet and Reset Pet.
- Settings: `codePet.idleTimeoutSeconds` and `codePet.gitReactions`.
